# Windows 定时提醒客户端 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 基于 `Qt6 + Python` 实现一个仅支持 Windows 的桌面定时提醒客户端，首期完成提醒管理、循环计时、托盘常驻、本地持久化、休息提醒、开机自启设置与自动提醒设置。

**Architecture:** 客户端采用 `PySide6` 构建界面与托盘能力，核心业务拆分为数据存储层、提醒调度层、系统集成层和界面层。提醒数据存储使用本地 `SQLite`，运行时以明确状态机管理提醒轮次，系统通知、音乐播放和开机自启分别通过独立服务封装，避免界面层直接耦合 Windows 细节；启动行为通过应用入口统一读取设置并决定是否自动开始全部提醒后缩到托盘。

**Tech Stack:** Python 3.12、PySide6、SQLite、pytest、pytest-qt

## 约束与实现口径

- UI 技术固定为 `PySide6`
- 本地持久化首期采用 `SQLite`，不用 JSON 文件，避免后续扩展困难
- 提醒名称做唯一校验，数据库层和业务层双重保证
- 编辑运行中提醒后，按新配置重置并暂停
- 休息间隔为 `0` 时，提醒后直接进入下一轮提醒
- 托盘关闭窗口不退出，只有明确“退出程序”才退出
- 开机自启默认关闭，启用后写入 Windows 自启动配置
- 自动提醒默认关闭，启用后每次启动程序都自动开始全部已启用提醒并缩到托盘

## 风险清单

- `PySide6` 的托盘、通知和多媒体能力在不同 Windows 环境下表现可能略有差异，需要尽早做真机验证
- `pytest-qt` 适合做基础 UI 交互测试，但不能完全覆盖真实桌面通知行为
- Windows 开机自启具体实现需要在“启动文件夹快捷方式”和“注册表”之间选一种，首期建议优先用更可控的方式封装
- 若未来要支持提醒统计、历史记录或删除恢复，SQLite 表结构要预留扩展字段；当前删除为不可恢复的物理删除
