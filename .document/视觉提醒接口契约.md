# 视觉提醒接口契约

## 1. 配置项

### 1.1 系统设置
- `ark_base_url`：Ark Responses 完整调用地址
- `ark_api_key`：Ark API Key
- `ark_model_name`：模型名

### 1.2 提醒配置
- `visual_reminder_enabled`：是否启用视觉识别
- `visual_music_path`：视觉识别结果需要补播时使用的独立音频文件

## 2. Ark 请求契约

### 2.1 请求方法
- `POST`

### 2.2 请求头
- `Authorization: Bearer <ARK_API_KEY>`
- `Content-Type: application/json`

### 2.3 请求体
```json
{
  "model": "doubao-seed-2-0-mini-260215",
  "input": [
    {
      "role": "user",
      "content": [
        {
          "type": "input_image",
          "image_url": "data:image/png;base64,......"
        },
        {
          "type": "input_text",
          "text": "请判断图片中的用户是否已经离开电脑前，只能返回以下三种结果之一：用户已离开电脑前、用户未离开电脑前、识别失败。"
        }
      ]
    }
  ]
}
```

## 3. 结果契约

模型返回结果只允许归一化为以下三种值：
- `用户已离开电脑前`
- `用户未离开电脑前`
- `识别失败`

程序处理规则：
- `用户已离开电脑前`：记录日志，不补播音频
- `用户未离开电脑前`：记录日志，补播一次视觉提醒音频
- `识别失败`：记录日志，不补播音频

## 4. 日志契约

每次模型调用都必须写入 `vision_decision_logs` 表。

### 4.1 字段
- `id`
- `reminder_id`
- `reminder_name`
- `request_url`
- `model_name`
- `result`
- `raw_response_text`
- `error_message`
- `captured_at`
- `requested_at`
- `completed_at`

### 4.2 约束
- `result` 必须是三态结果之一
- `raw_response_text` 保存模型返回的原始文本，失败时可为空
- `error_message` 在抓拍失败、请求失败、解析失败时写入

### 4.3 展示方式
- 主窗口提供“日志”按钮，点击后打开弹窗查看最近的视觉识别记录
- 弹窗至少展示完成时间、提醒名称、识别结果、错误信息、模型名称和请求地址
