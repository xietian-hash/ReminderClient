# 视觉识别提醒 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为定时提醒增加一条一次性的视觉识别链路，基于摄像头抓拍和 Ark 大模型返回结果判断是否需要补播提醒音，并把所有模型调用写入 SQLite 日志。

**Architecture:** 继续沿用现有的 `PySide6 + Python 3.11 + SQLite` 桌面架构，不新增第三方依赖。提醒到点后先走现有音频提醒链路，再由一个独立的视觉决策服务在 60 秒后抓拍图像、调用 Ark Responses API、解析三类结果并记录日志；若模型判断“用户未离开电脑前”，只补播一次视觉提醒音，其余结果只记日志不改变闹钟状态。摄像头采集、远程调用、结果归一化和日志落库都要可注入、可替换，避免把 UI、定时器和网络请求绑死在一起。

**Tech Stack:** Python 3.11、PySide6、SQLite、标准库 `urllib`/`json`/`base64`/`threading`、PyInstaller、pytest、pytest-qt

**Step 1: Write the failing test**

补测试覆盖：
- 提醒触发后，若启用视觉提醒，会安排一次 60 秒后的视觉判定
- 模型返回 `用户未离开电脑前` 时，只补播一次视觉提醒音
- 模型返回 `用户已离开电脑前` 时，不补播音频
- 模型调用失败时也要写日志，但不影响原提醒流程
- 取消提醒、重置提醒、退出程序时需要取消待执行的视觉定时任务

示例：
```python
def test_tick_schedules_visual_decision_when_enabled(reminder_service) -> None:

    reminder = repository.add(
        Reminder(
            name="涔呭潗鎻愰啋",
            reminder_interval_minutes=1,
            break_interval_minutes=5,
            visual_reminder_enabled=True,
        )
    )

    service.tick(reminder.id)

    assert service.has_pending_visual_decision(reminder.id) is True
```
